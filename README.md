# 3x-ui Panel — Railway Deployment 🚀

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/new/template?template=https://github.com/hyegvf/3x-ui)

دیپلوی پنل **3x-ui** (نسخه‌ی رسمی و آخرین ریلیز — در حال حاضر **v3.8.5**) روی **Railway** با استفاده از ایمیج رسمی `ghcr.io/mhsanaei/3x-ui:latest`.

> ⚡️ سریع‌ترین راه: روی دکمه‌ی **Deploy on Railway** بالا کلیک کنید — پروژه به‌صورت خودکار از همین ریپو ساخته می‌شود.

---

## ⚠️ مهم: محدودیت Railway برای پنل‌های پروکسی

Railway طبق سیاست‌های استفاده‌ی خود، سرویس‌های **پروکسی/VPN** را مجاز نمی‌داند و ورک‌اسپیس‌هایی که پنل‌هایی مثل 3x-ui را اجرا کنند ممکن است با پیام `Your workspace has been restricted` مسدود شوند.

- طبق پاسخ رسمی پشتیبانی Railway، این محدودیت معمولاً به‌خاطر «فعالیت شبکه‌ی خروجی مشکوک» اعمال می‌شود و حتی با ارتقای پلن هم ممکن است **برداشته نشود**.
- اگر خواستید پیگیری کنید: از [Station Railway](https://station.railway.com) تیکت بزنید — ولی انتظار واقع‌بینانه داشته باشید.
- **راه پیشنهادی و پایدار:** اجرای پنل روی **سرور مجازی (VPS)** — بخش «نصب روی سرور مجازی» در همین فایل را ببینید. 👇

---

## 🖥️ نصب روی سرور مجازی (VPS) — راه پیشنهادی

### روش ۱ — با Docker (از همین ریپو)

```bash
# پیش‌نیاز: داکر نصب باشد (curl -fsSL https://get.docker.com | sh)
git clone https://github.com/hyegvf/3x-ui.git
cd 3x-ui
docker compose up -d
```

- پنل: `http://<IP-سرور>:2053` — ورود اولیه: `admin` / `admin`
- فوراً از منوی تنظیمات، **نام کاربری، رمز و Base Path** را عوض کنید.
- برای اینباندهای Xray، پورت‌ها را در `docker-compose.yml` اضافه کنید یا `network_mode: host` را فعال کنید و فایروال (`ufw allow <port>`) را باز کنید.
- دیتابیس در پوشه‌ی `db/` ذخیره می‌شود و با آپدیت از بین نمی‌رود.

### روش ۲ — نصب رسمی بدون داکر (اسکریپت رسمی 3x-ui)

```bash
bash <(curl -Ls https://raw.githubusercontent.com/MHSanaei/3x-ui/main/install.sh)
```

بعد از نصب، دستور `x-ui` منوی مدیریت را باز می‌کند (پورت، رمز، SSL و...).

### به‌روزرسانی

```bash
cd 3x-ui
docker compose pull && docker compose up -d
```

این ریپو هیچ کدی از 3x-ui را کپی نمی‌کند؛ ایمیج **رسمی** پروژه در [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) مستقیماً کشیده می‌شود، بنابراین همیشه **آخرین نسخه‌ی رسمی** اجرا می‌شود.

## ✨ چه چیزهایی تنظیم شده؟

| فایل | توضیح |
|---|---|
| `Dockerfile` | بر پایه‌ی ایمیج رسمی 3x-ui (تگ `latest`)؛ fail2ban غیرفعال (Railway قابلیت `NET_ADMIN` نمی‌دهد) و اسکریپت استارت اضافه شده |
| `start.sh` | پورت پنل را هنگام بوت با پورت تخصیص‌یافته‌ی Railway (`$PORT`) هماهنگ می‌کند و دیتابیس را مقداردهی اولیه می‌کند |
| `railway.json` | بیلدر Dockerfile و سیاست ری‌استارت خودکار |

- منطقه‌ی زمانی پیش‌فرض ایمیج رسمی: `Asia/Tehran` ✅
- پورت پیش‌فرض پنل: `2053` (به‌صورت خودکار با `$PORT` هماهنگ می‌شود)

## 🚀 راه‌اندازی روی Railway

### مرحله ۱ — اتصال ریپازیتوری
1. وارد [Railway](https://railway.app) شوید (با GitHub لاگین کنید).
2. **New Project → Deploy from GitHub repo** را بزنید.
3. ریپازیتوری `3x-ui` را انتخاب کنید.
4. Railway خودکار `Dockerfile` را تشخیص می‌دهد و بیلد می‌گیرد.

> نکته: Railway از ریپوی خصوصی/عمومی شما بیلد می‌گیرد؛ نیازی به تنظیم اضافه‌ای نیست.

### مرحله ۲ — دامنه و پورت
1. بعد از دیپلوی موفق، به تب **Settings → Networking** سرویس بروید.
2. **Generate Domain** بزنید.
3. اگر Railway پورت هدف را نپرسید یا پورت اشتباه تشخیص داد، **Target Port** را دستی روی `2053` بگذارید (اسکریپت استارت در هر صورت خودش را با `$PORT` هماهنگ می‌کند).

### مرحله ۳ — ورود به پنل
- آدرس: `https://<دامنه-شما>/`
- نام کاربری: `admin`
- رمز عبور: `admin`

> ⚠️ **فوراً بعد از اولین ورود، از منوی Panel Settings نام کاربری، رمز عبور و Base Path را عوض کنید.** آدرس پنل بعد از تغییر Base Path به شکل `https://<دامنه>/<base-path>/` درمی‌آید.

## 💾 ذخیره‌سازی دائمی (اختیاری ولی توصیه‌شده)

بدون Volume، با هر دیپلوی مجدد، تنظیمات و اینباندها پاک می‌شوند (فایل‌سیستم موقتی است):

1. در سرویس، تب **Settings → Volumes** را باز کنید.
2. یک Volume بسازید و Mount Path را روی `/etc/x-ui` بگذارید.
3. سرویس را ری‌دیپلوی کنید.

---

## 🔄 به‌روزرسانی به آخرین نسخه

چون ایمیج برچسب `latest` را کش می‌کند:

1. در Railway، سرویس را باز کنید.
2. **Deploy → Redeploy** (یا در تب Deployments گزینه‌ی Redeploy) را بزنید.
3. Railway ایمیج را دوباره می‌کشد و آخرین ریلیز رسمی 3x-ui اجرا می‌شود.

اگر Volume بسته باشید، دیتابیس و اینباندها در به‌روزرسانی حفظ می‌شوند.

---

## 🌐 نکته‌ی اینباندها روی Railway

Railway ترافیک HTTP/HTTPS و WebSocket را روی دامنه‌ی سرویس پشتیبانی می‌کند:

- **پیشنهادی:** پروتکل‌های `VLESS` / `VMess` / `Trojan` با ترنسپورت `WS` یا `gRPC` + TLS (از Cloudflare یا TLS خود Railway).
- اینباند پنل روی همان پورت عمومی سرویس کار می‌کند؛ برای اینباندهای دیگر می‌توانید در Settings → Networking دامنه‌های اضافه با Target Portهای دیگر بسازید یا از **TCP Proxy** استفاده کنید.

## 🔧 متغیرهای محیطی (اختیاری)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | توسط Railway ست می‌شود | پورت پنل؛ اگر ست نشود `2053` |
| `XUI_DB_TYPE` | `sqlite` | امکان `postgres` (DSN لازم دارد) |
| `XUI_DB_DSN` | — | رشته‌ی اتصال PostgreSQL وقتی `XUI_DB_TYPE=postgres` است |

## 🛠️ رفع اشکال (Troubleshooting)

### ❌ خطای `You are creating projects too quickly`
این خطا **ربطی به پنل یا این ریپو ندارد** — محدودیت خودِ Railway است: هر ورک‌اسپیس فقط هر **۳۰ ثانیه** یک بار اجازه‌ی ساخت پروژه‌ی جدید دارد.

- ۳۰ تا ۶۰ ثانیه صبر کنید و فقط **یک بار** کلیک کنید.
- راه بهتر: یک پروژه بسازید (Empty Project) و داخل همان پروژه با **+ New → GitHub Repo** سرویس `3x-ui` را اضافه کنید — این کار پروژه‌ی جدید نمی‌سازد و مشمول محدودیت نیست.
- یا از دکمه‌ی **Deploy on Railway** بالای همین فایل استفاده کنید.

### ❌ پنل بعد از دیپلوی باز نمی‌شود
1. در تب **Deployments** لاگ‌های بیلد و ران‌تایم را ببینید؛ باید خط `[start.sh] Panel port configured successfully` را ببینید.
2. در **Settings → Networking** مطمئن شوید دامنه ساخته شده و **Target Port** درست است (پیش‌فرض `2053`).
3. اگر پورت را دستی عوض کردید، **Redeploy** بزنید — اسکریپت استارت پنل را با پورت جدید هماهنگ می‌کند.

### ❌ رمز admin/admin کار نمی‌کند
- اگر **Volume** ندارید: با هر دیپلوی، دیتابیس از نو ساخته می‌شود؛ یعنی رمز دوباره `admin/admin` است (پس حتماً همین اول عوضش کنید!).
- اگر **Volume** دارید و رمز را فراموش کردید: با Railway CLI و دستور `railway ssh` وارد بشوید و اجرا کنید:
  ```bash
  /app/x-ui setting -username myuser -password MyStrongPass123
  ```

### ❌ سرویس بعد از مدت‌ها بی‌استفاده خوابید
- در `railway.json` مقدار `sleepApplication: false` ست شده است؛ اگر باز هم خوابید (پلن Trial)، پلن را ارتقا دهید یا سرویس را دستی **Restart** کنید.

### ❌ بیلد خطای pull از ghcr می‌دهد
- خطای موقتی شبکه/رجیستری است؛ یک بار **Redeploy** بزنید.
